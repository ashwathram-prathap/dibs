# Round 10 artwork

The Registry seal uses the `d.` monogram from the same self-hosted Archivo Black face as the wordmark (SIL Open Font License, bundled in `public/fonts`). Generated by `scripts/r10-seal.ts`. Both legends use centered SVG textPaths, identical 14-unit weight/size/tracking, concentric rings and exact horizontal separator dots. The lower path's baseline radius accounts for inward-facing text. The Worker version is mechanically outlined from those paths by resvg, with the same font. No hand ornament or tracing is used.

Animals: Albrecht Dürer, *The Rhinoceros*, 1515, woodcut; Cleveland Museum of Art, accession 1993.9. Public-domain Open Access image, unchanged file downloaded from https://openaccess-cdn.clevelandart.org/1993.9/1993.9_web.jpg . Source record: https://www.clevelandart.org/art/1993.9 and https://openaccess-api.clevelandart.org/api/artworks/1993.9 . CSS supplies monochrome ink/paper treatment. This historic depiction is an artwork, not an anatomical reference.

The weak Round 9 icon plates are no longer displayed. Categories without a suitable print use typography and paper stock alone, as permitted by FIXES-R10.md. Animals is the only retained plate, so there is no conflicting engraving style.
