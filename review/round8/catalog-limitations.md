## Sample interpretation

Some frozen samples contain spelling or scope problems. The football sample spells “Arumugan Rengasamy”; source names use “Arumugam Rengasamy”, which is accepted after removing the source honorific. The video-game sample uses “Shippudden” and names a compilation not separately identified by the current source set; this is not claimed to be only a typo. The painter pool includes a sculptor and a photographer as well as a genuine classification gap. These original misses remain visible and are not credited as exact matches.

Before opening an affected category, add an appropriately licensed authoritative reference or individually verify and record genuine missing names, then rerun the original lists and a fresh independently scoped audit. Keep historical failures. The clerk queue supplies real player submissions for subsequent review; it never automatically approves answers. No additional dates were added.
